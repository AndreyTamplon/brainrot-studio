# Защита Project Proposal

HTML-презентация Brainrot Studio: 15 основных слайдов и 3 резервных. Внутри есть заметки докладчика, источники и переход к живому демо приложения.

[PDF-версия](brainrot-studio-proposal.pdf) содержит все 18 слайдов, включая резервные, с кликабельными ссылками. Заметки докладчика и интерактивные панели доступны в HTML.

## Открытие

Скачайте [готовый HTML](brainrot-studio-proposal.html) и откройте его в браузере. Изображения, шрифты, стили и скрипты встроены в файл. Для показа слайдов сервер не нужен.

Клавиши: стрелки или пробел для навигации, `F` для полного экрана, `N` для заметок, `S` для источников, `O` для оглавления, `P` для окна докладчика. Остальные команды доступны по кнопке `?`.

Для живого демо запустите приложение по [инструкции проекта](../README.md#локальный-запуск). Адрес приложения можно изменить в настройках презентации через кнопку `?`.

## Редактирование и сборка

- `build/deck.source.html` - содержание слайдов и редактируемые SVG-схемы.
- `build/deck.css` и `build/revision.css` - оформление.
- `build/deck.js` - управление, заметки докладчика и источники.
- `assets/` - изображения, исходные иллюстрации и шрифты. Сохранены также материалы, полученные при подготовке предыдущих вариантов.
- `build/build.py` - сборка автономного HTML без сторонних зависимостей Python.

Из корня репозитория:

```sh
python3 project-proposal-defense/build/build.py
```

Скрипт обновляет `brainrot-studio-proposal.html` в этой папке. После изменений исходников пересоберите HTML перед коммитом.

## Источники материалов

Ссылки на исследования, индустриальные примеры и изображения доступны в презентации и в `build/deck.js`. Записи о загрузке части исходных файлов сохранены в `assets/asset-origins.json`. Лицензия шрифта Manrope находится в `assets/font-license.txt`.
