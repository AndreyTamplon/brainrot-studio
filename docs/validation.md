## Воспроизведение

Бесплатные проверки описаны в README. Для платной проверки работающего сервера:

```sh
uv run python scripts/acceptance.py --report data/my-acceptance.json
```

`--cases` ограничивает набор сценариев; повтор с тем же путём отчёта продолжает наблюдение за созданными заданиями. Перед запуском проверьте параметры через `--help` и установленные лимиты расходов.

Ролики и подробные отчёты находятся в локальном `data/` и не публикуются с исходниками. Автоматическая приёмка не гарантирует фактическую точность: в ходе разработки обнаруживались ошибки чисел, оговорок и выбора иллюстраций, пропущенные модельными проверками.
